# How to write docs

Start with the thing the reader needs to know or do.
Use plain words and short paragraphs. Keep the details that help someone use or change the app.

Show commands near the instructions. Separate what works from what is still planned.
Use checklists for unfinished work and simple headings when they help.

Skip marketing copy, repeated introductions, and conclusions that repeat the text.
Don't use em dashes.
