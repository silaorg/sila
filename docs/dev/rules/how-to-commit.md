# Git commits

Use imperative mood and use a prefix for the type of change.

Examples:

```text
feat(auth): add user login
fix(payment): resolve gateway timeout
ci: update release workflow
docs: update README
deps: aiwrapper to 3.0.1
dev: add package aliases to the SvelteKit config
```

## Commit types

- Product feature: `feat(name): description`
- Product fix: `fix(name): description`
- Build, release, or CI: `ci: description`
- Tests: `tests: description`
- Documentation: `docs: description`
- Dependencies: `deps: description`
- Developer tooling: `dev: description`
